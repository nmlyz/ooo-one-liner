ooo-one-liner writes one line to a text file: a one-line out-of-office email reply. The line was picked from 36 candidates by pairwise judging against the brief — a real away message whose joke is the message itself: the sender is out, and the chair has been promoted to their position. No beach, no inbox, no "limited access to email": the replacement is sitting right there.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 57 characters, a single line, and ends on its strongest beat. The program checks the result against the entry gate (1–160 characters, single line, no leading or trailing space) before writing it, then reads the file back to confirm the bytes match.
